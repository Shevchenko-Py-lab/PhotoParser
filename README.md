# PhotoParser

Оконное приложение для копирования исходных RAW-фотографий по именам отобранных изображений.

## Возможности

- Отбор по `.jpg`, `.jpeg`, `.png`.
- Поиск и копирование `.cr2`, `.cr3`, `.raw` во вложенных папках.
- Сопоставление по имени без расширения и без учёта регистра.
- Если для имени доступны разные RAW-форматы, копируются все.
- Несколько файлов одного RAW-формата с одинаковым именем пропускаются с записью в отчёт.
- Исходники сохраняются; существующие копии не перезаписываются и не проверяются на идентичность.
- Выбор папок кнопками или вставкой пути из Проводника.
- Копирование в фоне, журнал работы и текстовый отчёт.

## Запуск на Windows

1. Скачайте проект через **Code → Download ZIP** и распакуйте весь архив.
2. Запустите `Запустить.bat`.
3. Выберите папку с отобранными изображениями, папку с RAW и папку для копий.
4. Нажмите **Скопировать RAW**.

Если папка результата не указана, создаётся `Отбор_RAW` внутри папки с отбором.

Bootstrap сначала ищет установленный Python 3.11+ с Tkinter через Python Launcher, PATH и реестр. Если подходящего Python нет, он скачивает официальный установщик Python 3.11.9 x64 с python.org, проверяет цифровую подпись и пытается установить runtime в `%LOCALAPPDATA%\PhotoRawSelector\Python311`. Первый запуск без установленного Python требует интернета. PATH и ассоциации файлов не меняются.

Комплект рассчитан на Windows 10/11 x64. Запуск bootstrap на Windows в среде разработки не проверялся.

## Запуск с установленным Python

```bat
py -3.11 app.py
```

Сторонние Python-библиотеки не требуются. Нужен Tkinter (в стандартном Windows-установщике Python — компонент Tcl/Tk).

## Файлы

- `app.py` — GUI и логика сопоставления/копирования.
- `bootstrap.ps1` — поиск или установка Python и запуск приложения.
- `Запустить.bat` — точка входа для Windows.

## Ограничения

Файлы сопоставляются по имени, а не по метаданным или содержимому. Существующие копии считаются уже обработанными. При ошибке копирования готовые копии сохраняются; после устранения причины можно повторить запуск. Окно нельзя закрыть до окончания копирования.
